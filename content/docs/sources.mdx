---
title: "Sources"
description: "Add PDFs, Markdown and text files, web pages or pasted text to a notebook, and choose which sources the chat and Studio use."
---

A **source** is a document you add to a notebook. better-vault stores it as plain text, splits it into passages and uses those passages to answer questions and create Studio outputs.

## Supported sources

| Kind          | How to add it                                   |
| ------------- | ----------------------------------------------- |
| **PDF**       | Upload (up to 20 MB). Text-based PDFs work best. |
| **Markdown**  | Upload a `.md` file.                            |
| **Text**      | Upload a `.txt` file, or **Paste text**.        |
| **Web page**  | **Web page** tab, then the full address. The page's main text is saved. |

More kinds (DOCX, EPUB, YouTube transcripts, images and audio) are on the [roadmap](/docs/roadmap).

## Add sources

Open the **Sources** tab and choose **Add source**, or use **Add a source** in the chat. You can drop several files at once.

## Select which sources to use

Only **selected** sources are used, in the chat and in the Studio. Tick or untick a source to include it, or use **Select all sources**. The counter shows how many are selected.

## Read, rename or delete

Each source has a menu to **Read** its saved text, open the original page, rename it or delete it. Deleting a source keeps the chats and outputs that were made from it.
