# Format marks

Logos of common file formats, shown as small badges on folder and file tiles
on the Vault page (`components/home/vault-tiles.tsx`). Downloaded from
[theSVG](https://thesvg.org) (its repository is MIT-licensed):
`microsoft-word`, `microsoft-excel`, `microsoft-powerpoint`, `pdf`,
`markdown`, `html5`, `youtube` and `json`, each in its default (full-colour)
version, except `markdown`, which is its `light` variant (dark lines for the
white badge). Each mark is a trademark of its owner and is used only to say what
kind of file a tile holds; it implies no endorsement. Formats without a mark
here are drawn with Hugeicons.
