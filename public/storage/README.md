# Storage marks

Logos of the storage services better-vault can connect to, shown in
Settings → Storage. Downloaded from [theSVG](https://thesvg.org) (published
there under CC0-1.0): `google-drive-2026`, `microsoft-onedrive`,
`aws-amazon-simple-storage-service` and `cloudflare` (for R2) and `google` (the "Continue with Google" button), each
in its full-colour version. Each mark is a trademark of its owner and is used only
to say that better-vault works with that service; it implies no endorsement.
