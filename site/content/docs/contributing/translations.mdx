---
title: "Translations"
description: "Translate the better-vault interface into a new language with i18next: copy the English files, register the language, and check that no keys are missing."
---

The interface is fully translatable with [i18next](https://www.i18next.com), and English in `locales/en/` is the source of truth.

<Steps>
<Step>

### Copy the English files

Copy `locales/en/` to `locales/<code>/`, for example `locales/fr/`, and translate the values but not the keys.

</Step>
<Step>

### Register the language

Import the new files in `lib/i18n/resources.ts`, then add the language to `lib/i18n/config.ts`. Give right-to-left scripts `dir: "rtl"`.

</Step>
<Step>

### Check it

Run the locale check, which lists missing or extra keys:

```bash
npm run i18n:check
```

When it passes, open a pull request.

</Step>
</Steps>

The website and the documentation are in English for now.
