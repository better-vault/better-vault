better-vault is an app you run yourself: on your own computer, or on a server you control. It opens in your browser and keeps your notebooks there. This guide takes you from nothing to your first cited answer in a few minutes.

## Install and run

**You need:** [Node.js](https://nodejs.org) 20.9 or newer (it includes npm) and [Git](https://git-scm.com).

<Steps>
<Step>

### Download better-vault

```bash
git clone https://github.com/better-vault/better-vault.git
cd better-vault
```

</Step>
<Step>

### Install and start it

```bash
npm install
npm run dev
```

</Step>
<Step>

### Open it

Go to [http://localhost:3000](http://localhost:3000) in your browser. No account, no `.env` file.

</Step>
</Steps>

For a faster production build, run `npm run build` and then `npm start`. To run it for other people, see [Self-hosting](/docs/self-hosting). A desktop app is on the [roadmap](/docs/roadmap).

## Connect a model

Open **Settings → AI providers** and choose one:

- **An API key** from OpenAI, Anthropic (Claude) or Google (Gemini). Paste it, and the model list loads from the provider.
- **A local model** with Ollama or LM Studio running on the same computer. Nothing leaves your machine.

[Providers and models](/docs/providers) explains where to get keys and which models suit which tools.

## Make your first notebook

<Steps>
<Step>

### Create a notebook

On the notebooks page, choose **New notebook**. Rename it from the name at the top centre.

</Step>
<Step>

### Add sources

Choose **Add a source**: upload PDF, Markdown or text files, add a web page by its address, or paste text. Only selected sources are used. See [Sources](/docs/sources).

</Step>
<Step>

### Ask a question

Type in the prompt bar. Answers come from your sources with numbered citations; point at one to read the passage. Switch to **Web** to let the model search the internet too. See [Chat and citations](/docs/chat).

</Step>
<Step>

### Create something

Choose **Create** at the top left and pick a tool: a report, flashcards, a quiz, a mind map, a slide deck and more. Outputs open in the **Studio** tab, ready to download. See [the Studio](/docs/studio).

</Step>
</Steps>

## Keep your work

Notebooks live in your browser. Export a backup from **Settings → Data** now and then, especially before clearing site data. See [Privacy and your data](/docs/privacy).
