A source is a document you add to a notebook. better-vault stores it as plain text and splits it into passages, which it uses to answer questions and to create Studio outputs.

<Screenshot name="sources" alt="The Sources tab of a notebook with a PDF, a web page and Markdown notes selected" />

## Supported sources

| Kind                                    | How to add it                                                                                   |
| --------------------------------------- | ----------------------------------------------------------------------------------------------- |
| **PDF**                                 | Upload a file of up to 20 MB. Text-based PDFs work best.                                        |
| **Word, Excel and PowerPoint**          | Upload a `.docx`, `.xlsx` or `.pptx` file. Each sheet becomes rows; each slide keeps its notes. |
| **EPUB books**                          | Upload a `.epub` file. Its chapters are read in order.                                          |
| **Markdown and text**                   | Upload a `.md` or `.txt` file, or choose **Paste text**.                                        |
| **CSV, JSON, HTML, XML, YAML and code** | Upload the file. better-vault reads it as text and shows its format.                            |
| **Web page**                            | Open the **Link** tab and enter the full address. Its main text is saved.                       |
| **YouTube video**                       | Open the **Link** tab and paste the video's address. Its transcript is saved.                   |

Each source shows its format, such as CSV, Word document or YouTube video, with its own icon in the list, the reader and citations. Images and audio are on the [roadmap](/docs/roadmap).

## YouTube videos

better-vault adds a YouTube video the way NotebookLM does: it imports the video's transcript, from captions the uploader wrote or YouTube made automatically. The video needs to be public and have captions; a private video, or one without captions, can't be added, and the dialog says why.

The transcript keeps a time, such as `[4:05]`, at the start of each paragraph, so citations point at a moment in the video. In the reader, the video plays above the transcript in YouTube's privacy-enhanced player, and pressing a time starts it there.

## Add sources

Open the **Sources** tab and choose **Add source**, or use **Add a source** in the chat. You can drop several files at once.

## Choose which sources to use

The chat and the Studio use only the sources that are selected. Tick or untick a source to include it, or choose **Select all sources**. The counter shows how many are selected.

## Read, rename or delete

Each source has a menu. **Read** shows the text better-vault saved, and for a web page or video you can open the original. You can also rename or delete the source. Deleting it keeps the chats and outputs that were made from it.
