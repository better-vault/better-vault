title: "Sources"
description: "Add PDFs, Markdown and text files, web pages or pasted text to a notebook in better-vault, then choose which of those sources the chat and the Studio use."
---

A source is a document you add to a notebook. better-vault stores it as plain text and splits it into passages, which it uses to answer questions and to create Studio outputs.

## Supported sources

| Kind         | How to add it                                                           |
| ------------ | ----------------------------------------------------------------------- |
| **PDF**      | Upload a file of up to 20 MB. Text-based PDFs work best.                |
| **Markdown** | Upload a `.md` file.                                                    |
| **Text**     | Upload a `.txt` file, or choose **Paste text**.                         |
| **Web page** | Open the **Web page** tab and enter the full address. Its main text is saved. |

DOCX, EPUB, YouTube transcripts, images and audio are on the [roadmap](/docs/roadmap).

## Add sources

Open the **Sources** tab and choose **Add source**, or use **Add a source** in the chat. You can drop several files at once.

## Choose which sources to use

The chat and the Studio use only the sources that are selected. Tick or untick a source to include it, or choose **Select all sources**. The counter shows how many are selected.

## Read, rename or delete

Each source has a menu. **Read** shows the text better-vault saved, and for a web page you can open the original. You can also rename or delete the source. Deleting it keeps the chats and outputs that were made from it.
