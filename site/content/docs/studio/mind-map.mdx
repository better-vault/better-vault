The **Mind map** tool draws the ideas in your sources as a diagram. The default is an interactive mind map: open and close branches, and click a topic to ask about it in the chat.

## Diagram kinds

Mind map, Flowchart, Timeline, Sequence, Stages, Concept model, Relationships, Quadrant chart, Journey, Cause and effect (fishbone), Kanban board and Gantt chart.

## Options

- **Diagram:** one of the kinds above.
- **Detail:** concise, standard or detailed.

## How it is made

The model writes the diagram as Mermaid text. better-vault checks it with [Pele](https://pele.run), asks the model to repair it if it doesn't render, and draws it as SVG.

## Download

PNG, SVG or the Mermaid source (`.mmd`).
