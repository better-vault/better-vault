---

The Mind map tool draws the ideas in your sources as a diagram. By default it makes an interactive mind map: you can open and close branches, and click a topic to ask about it in the chat.

## Options

| Option      | Choices                                                                                                                                                       |
| ----------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **Diagram** | Mind map, Flowchart, Timeline, Sequence, Stages, Concept model, Relationships, Quadrant chart, Journey, Cause and effect (fishbone), Kanban board or Gantt chart |
| **Detail**  | Concise, standard or detailed                                                                                                                                 |

## How it is made

The model writes the diagram as Mermaid text. better-vault checks it with [Pele](https://pele.run), asks the model to repair it if it doesn't render, and draws it as SVG.

## Download

Download the diagram as PNG, SVG or its Mermaid source (`.mmd`).
