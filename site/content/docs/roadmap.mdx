better-vault's roadmap: what has shipped, what comes next, and what is out of scope. Version numbers are plans, not promises; the order can change with feedback. To suggest something, [open a feature request](https://github.com/better-vault/better-vault/issues/new/choose).

## Shipped

- **v0.1.0:** notebooks and sources (text, Markdown, PDF, web pages), chat in Sources and Web modes with citations, Reports, Flashcards, Quiz, Data table and Mind map.
- **v0.2.0:** Slide deck, Infographic (provider image models), Anatomy figures, Whiteboard with Annotate, several chats per notebook, citation marks and footnotes.
- **Next release:** this website and documentation at [better-vault.dev](https://better-vault.dev).

## v0.3: Understand your notebook

- **Notebook guide:** a summary of the notebook, its key topics and suggested questions, refreshed when sources change.
- **Notes:** write your own notes, save a chat answer as a note, and turn notes into sources.
- **Chat settings:** a goal or persona for the notebook, an answer style (default, learning guide, custom) and answer length.
- **Learning guide:** a tutor mode that asks questions back and works through problems step by step instead of giving the answer at once.
- **Output language:** choose the language of answers and Studio outputs, separately from the interface language.
- **More report formats:** FAQ and timeline templates beside briefing doc, study guide and blog post.

## v0.4: More sources and research

- **More source types:** DOCX, EPUB, YouTube transcripts, images (read by vision models) and audio files (transcribed by the provider's speech-to-text, as sources only).
- **Discover sources:** describe a topic and let the model find web pages with its provider's built-in search, then add the ones you choose.
- **Deep research:** a longer, background search that writes a cited report you can add as a source.
- **Better retrieval:** embedding-based search over passages, alongside today's keyword search.

## v0.5: Desktop app (Electron)

- Apps for **macOS, Windows and Linux** with the same interface as the web app.
- Notebooks stored as files in a folder you choose, with import of browser backups.
- API keys kept in the operating system's keychain.
- Works offline with Ollama and LM Studio, with no setup beyond the model server.
- Add whole folders of documents as sources by dragging them in.
- Signed builds and automatic updates.

## v0.6: Edit and share

- **Edit Studio outputs with a prompt:** change one slide, one section of a report or one branch of a mind map.
- **Review the outline** of a slide deck before it is built.
- **Share a notebook as a file**, and copy a notebook.

## Later

- More providers: OpenRouter and Vercel AI Gateway.
- More interface languages.
- A layout made for phones, installable as an app.
- Example notebooks on this site to try better-vault without your own files.

## Not planned

- **Audio and video overviews.** better-vault focuses on cited chat and written and visual outputs.
- **Accounts and server storage.** better-vault stays local-first: your data lives on your device.
