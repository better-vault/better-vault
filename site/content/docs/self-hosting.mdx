title: "Self-hosting"
description: "Deploy your own copy of better-vault on any Node.js host or Vercel, with optional settings for public deployments."
---

better-vault is a standard Next.js app with stateless API routes and no database, so it runs anywhere Node.js 20.9+ runs.

## Build and start

```bash
npm install
npm run build
npm start
```

The app is served at the root of its address, for example `http://localhost:3000`. This website is a separate project and is not part of the app.

## Vercel

Import the repository in Vercel. No environment variables or storage are required. API routes run as functions and only forward requests to the provider each user picks.

## Environment variables

Both are optional.

| Variable                             | Default | Effect                                                                                                                    |
| ------------------------------------ | ------- | ------------------------------------------------------------------------------------------------------------------------- |
| `BETTER_VAULT_ALLOW_LOCAL_PROVIDERS` | `true`  | Set to `false` to turn off Ollama and LM Studio. Their address comes from the user, so on a public server they would make the server fetch any address. |
| `BETTER_VAULT_ALLOW_PRIVATE_URLS`    | `false` | Set to `true` to let web-page sources point at private or local network addresses. Only for trusted, private installs.    |
| `NEXT_PUBLIC_SITE_URL`               | `https://better-vault.dev` | The site's own address, used in canonical links, the sitemap and social cards.                               |

## Public deployments

For an install that strangers can reach, set `BETTER_VAULT_ALLOW_LOCAL_PROVIDERS=false` and leave private URLs off. Each user still brings their own key, which stays in their browser.
