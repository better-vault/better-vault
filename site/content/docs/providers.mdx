better-vault works with five providers: you bring the key or the local server, and you pick the provider and model for each question in the prompt bar.

| Provider            | Needs                          | Web mode | Pictures (Infographic)    |
| ------------------- | ------------------------------ | -------- | ------------------------- |
| **OpenAI**          | API key                        | Yes      | Yes (GPT Image models)    |
| **Anthropic**       | API key                        | Yes      | No                        |
| **Google (Gemini)** | API key                        | Yes      | Yes (Gemini image models) |
| **Ollama**          | Ollama running on your machine | No       | No                        |
| **LM Studio**       | LM Studio's local server       | No       | No                        |

## Add an API key

<Steps>
<Step>

### Get a key

Create one in the provider's console: [OpenAI](https://platform.openai.com/api-keys), [Anthropic](https://console.anthropic.com/settings/keys) or [Google AI Studio](https://aistudio.google.com/apikey).

</Step>
<Step>

### Paste it in better-vault

Open **Settings → AI providers**, choose the provider and paste the key. better-vault loads the model list from the provider with your key, so new models appear without an update.

</Step>
</Steps>

Your key is stored on your device and sent only with the requests that need it. [Privacy](/docs/privacy) explains what is sent where.

## Use a local model

<Steps>
<Step>

### Install a model server

Install [Ollama](https://ollama.com) or [LM Studio](https://lmstudio.ai) and download a model. With Ollama, this downloads a small one:

```bash
ollama pull llama3.2
```

</Step>
<Step>

### Run better-vault on the same computer

Use the [desktop app](/docs/desktop), or run the web app yourself as shown in [Get started](/docs/quickstart#install-and-run).

</Step>
<Step>

### Turn the provider on

In **Settings → AI providers**, enable Ollama (`http://localhost:11434`) or LM Studio (`http://localhost:1234`), then pick the model in the prompt bar.

</Step>
</Steps>

With a local model, your sources never leave your computer. Web mode is not available, because it relies on a provider's built-in search.

## Which model should I use?

Any recent large model works for chat and reports, and larger models follow citations more closely. Studio tools that return structured data, such as quizzes, flashcards and Anatomy, need a model that follows JSON schemas well; small local models may need a retry.

For infographics, you choose an image model in the tool's dialog. Its key is sent with that request only.
