A **notebook** in better-vault is a workspace for one topic, course or project. Each notebook keeps its own sources, its own chats (listed in **History**) and its own Studio outputs.

## The notebook screen

- **Top left:** **Settings** and **Create** (opens the Studio), and in the Chat tab, **History**.
- **Top centre:** the notebook's name. Click it to switch notebooks, create a new one, rename or delete it.
- **Top right:** tabs for **Chat**, **Sources** and **Studio**.
- **Bottom, in the Chat tab:** the prompt bar, with the model picker and the Sources / Web switch.

## Create a notebook

Choose **New notebook** on the notebooks page (the app's home), or from the notebook name menu. Then add [sources](/docs/sources).

## Chats and History

A notebook can hold several chats. Open **History** to see them grouped by day, open an older one, rename or delete it, or start a **New chat**.

## Delete a notebook

Open the name menu and choose **Delete notebook**. Its sources, chats and outputs are removed from this browser and can't be recovered unless you exported a backup in **Settings → Data**.
