# Provider marks

Logos of the AI providers better-vault works with, shown on the landing page.
Downloaded from [theSVG](https://thesvg.org) (published there under CC0-1.0).
Each mark is a trademark of its owner and is used only to say that
better-vault works with that provider; it implies no endorsement.

`lmstudio-light.svg` and `lmstudio-dark.svg` are the same file with its
`currentColor` fill set to black and white.
